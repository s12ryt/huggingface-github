# 項目表 — 檔案與依賴關係

> 本檔記錄每個檔案/目錄的職責與相互依賴。新增檔案時必須同步更新。
> 工程約束：`src/` 內部一律用相對路徑 import（`../x/y.js`），只有 `tests/` 可用 `@/` alias。

## 頂層

| 路徑 | 職責 |
|---|---|
| `package.json` | 依賴、scripts、`prisma.schema` 指向 `prisma/schema` 多檔目錄 |
| `tsconfig.json` | 型別檢查用（`noEmit`、`moduleResolution: bundler`、含 tests、有 `@/` paths） |
| `tsconfig.build.json` | 產出用（`NodeNext`、`outDir: dist`、`paths: {}`，故 src 不可用 alias） |
| `vitest.config.ts` | `globalSetup` 指向 `tests/setup/global.ts`；alias 以陣列正則把 `@/x.js` 映回 `src/x.ts` |
| `.env.example` | 全部環境變數的註解範本 |
| `LICENSE` | Apache-2.0 全文 |
| `README.md` | 開源專案說明：架構、部署、組態、API、安全性設計 |
| `Dockerfile` | 多階段建置（build → runtime，非 root，掛載 data 與 cache 卷冊） |
| `docker-compose.yml` | 單服務部署，必填環境變數以 `${VAR:?}` 強制 |
| `.dockerignore` | 排除 node_modules / dist / tests / data / .env / agent |

## `src/storage/` — HuggingFace 加密儲存層（輪次 4 取代 `src/onedrive/`）

| 檔案 | 功能 | 依賴 |
|---|---|---|
| `ranges.ts` | `mergeRanges`（E+4 相鄰 Range 合併）、`rangeHeader`、`sliceFromSpan` | — |
| `lru.ts` | `LruCache`（E+6 有界密文快取，含 `deletePrefix`） | — |
| `crypto.ts` | `parseMasterKey`、`deriveFileKey`（HKDF 依路徑）、GCM 分塊加解密、`cipherRangeFor` 明文↔密文位移換算 | ranges |
| `lfs.ts` | `isLfsPointer`（前 14 byte 即可判定）、`parseLfsPointer`、`lfsOid`、`requestLfsBatch` | — |
| `hf.ts` | `createHubClient`（commit API、resolve、Range、LFS 上傳下載與 href TTL 快取、退避重試）、`shouldUseLfs` | ranges, lfs |
| `store.ts` | `createHubStore`：`Store` 契約的唯一實作，加密對上層透明 | ranges, lru, crypto |

**`Store` 介面**（上層唯一依賴的契約）：`readRanges` / `readAll` / `readJson` / `putBytes` / `putJson` / `remove` / `cacheStats`。
換後端時只要重新實作這個介面，git 與 issue/PR 的程式碼都不用動。

## 依賴方向（由底層往上，無循環）

```
config  →  auth  →  users
   ↓        ↓         ↓
settings  invite      │
   ↓                  ↓
storage  →  git  →  repos / issues / pulls
                        ↓
                  http/routes  →  http/app  →  server.ts
                        ↑
                      web
```

`config` 依賴 `storage/crypto` 的 `parseMasterKey`（僅此一處反向，是金鑰格式守門，不構成循環）。
